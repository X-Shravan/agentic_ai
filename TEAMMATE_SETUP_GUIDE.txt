2️⃣  PYTHON SETUP
═══════════════════════════════════════════════════════════════════════════════

STEP 2.1: Download Python
─────────────────────────────────────────────────────────────────────────────
1. Go to: https://www.python.org/downloads/
2. Download: Python 3.10 (click the big yellow button)
   IMPORTANT: Make sure it says "Python 3.10" NOT 3.11 or 3.12
3. Run the installer
4. ⚠️  CRITICAL: Check "Add Python to PATH" (bottom checkbox)
5. Click "Install Now"
6. Wait for installation to complete

Verify Installation:
─────────────────────────────────────────────────────────────────────────────
1. Open PowerShell (search "PowerShell" in Windows)
2. Type: python --version
3. You should see: Python 3.10.x
   
   If you see an error, reinstall Python and CHECK "Add Python to PATH"


STEP 2.2: Update pip
─────────────────────────────────────────────────────────────────────────────
1. Open PowerShell
2. Run this command:

   python -m pip install --upgrade pip

3. Wait for it to complete

4️⃣  DEPENDENCIES INSTALLATION
═══════════════════════════════════════════════════════════════════════════════

STEP 4.1: Create Virtual Environment (RECOMMENDED)
─────────────────────────────────────────────────────────────────────────────
This creates an isolated Python environment for this project (best practice).

1. Open PowerShell in project folder
2. Run:

   python -m venv .venv

3. Wait for "venv" folder to be created (takes 1-2 minutes)
4. Activate virtual environment:

   .\.venv\Scripts\Activate.ps1

5. You should see "(.venv)" at start of PowerShell line
   Example: (.venv) PS C:\Users\YourName\Desktop\mini_project>

Note: You must run this activation command EVERY TIME you open PowerShell
      to work on this project!


STEP 4.2: Install All Required Packages
─────────────────────────────────────────────────────────────────────────────
1. Make sure you're in project folder and (.venv) is activated
2. Run this command:

   pip install reportlab opencv-python opencv-contrib-python numpy mediapipe flask pyyaml pillow

3. Wait for all packages to install (takes 5-10 minutes)
   You should see: "Successfully installed ..." at the end

Full Package List:
  ✓ reportlab       - PDF report generation
  ✓ opencv-python   - Computer vision
  ✓ opencv-contrib  - OpenCV extra modules
  ✓ numpy           - Numerical computing
  ✓ mediapipe       - Head pose detection
  ✓ flask           - Web server
  ✓ pyyaml          - Configuration
  ✓ pillow          - Image processing


STEP 4.3: Verify Installation
─────────────────────────────────────────────────────────────────────────────
Run this to verify all packages installed:

   pip list

You should see all packages listed above with version numbers.

5️⃣  EMAIL CONFIGURATION (IMPORTANT!)
═══════════════════════════════════════════════════════════════════════════════

STEP 5.1: Enable 2-Factor Authentication on Gmail
─────────────────────────────────────────────────────────────────────────────
1. Go to: https://myaccount.google.com/security
2. Login to your Gmail account
3. Find "2-Step Verification" section
4. Click "Get Started"
5. Verify your phone number
6. Complete the 2FA setup
7. Return to security page


STEP 5.2: Generate Gmail App Password
─────────────────────────────────────────────────────────────────────────────
1. Go to: https://myaccount.google.com/apppasswords
2. You should see dropdown for "Select app" and "Select device"
3. Select: "Mail" from first dropdown
4. Select: "Windows Computer" from second dropdown
5. Click "Generate"
6. Google will show a 16-character password like: xxxx xxxx xxxx xxxx
7. COPY THIS PASSWORD (you'll need it in next step)

⚠️  IMPORTANT: This is NOT your Gmail password! It's different!


STEP 5.3: Run Email Setup Wizard
─────────────────────────────────────────────────────────────────────────────
1. Open PowerShell in project folder
2. Make sure (.venv) is activated
3. Run:

   python setup_wizard.py

4. Follow the prompts:
   - When asked to continue: Type "y" and press Enter
   - For "Install missing packages": Type "n" (they're already installed)
   - For "Setup email": Type "y"
   - Enter your Gmail address (e.g., your.name@gmail.com)
   - Enter the 16-character App Password you copied (with spaces)
   - Enter recipient email (where reports should be sent)
   - The wizard will test the connection

✅ If successful, you'll see: "Email configured for: your.email@gmail.com"

📁 This creates a file: email_config.txt (auto-generated)

8️⃣  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Python is not recognized as an internal command"
─────────────────────────────────────────────────────────────────────────────
Fix: Python not added to PATH during installation
  1. Uninstall Python: Settings → Apps → Python
  2. Reinstall Python from: https://www.python.org/downloads/
  3. ⚠️  CHECK "Add Python to PATH" checkbox during installation


PROBLEM: "(.venv) not showing" in PowerShell
─────────────────────────────────────────────────────────────────────────────
Fix: Virtual environment not activated
  1. In PowerShell, run:
     
     .\.venv\Scripts\Activate.ps1

  2. You should see "(.venv)" prefix now


PROBLEM: "ModuleNotFoundError: No module named 'reportlab'"
─────────────────────────────────────────────────────────────────────────────
Fix: Packages not installed
  1. Make sure (.venv) is activated
  2. Run:
     
     pip install reportlab

  3. Try again: python main.py


PROBLEM: "Email not sending" or "Authentication failed"
─────────────────────────────────────────────────────────────────────────────
Fix: Email configuration issue
  1. Check: Did you use Gmail App Password (NOT regular password)?
  2. Check: Is 2FA enabled on Gmail?
  3. Check: email_config.txt exists
  4. Re-run: python setup_wizard.py
  5. Follow all prompts again


PROBLEM: Camera window doesn't open
─────────────────────────────────────────────────────────────────────────────
Fix: No camera connected or permission issue
  1. Connect webcam to laptop
  2. Check Windows Settings: Privacy → Camera
  3. Ensure camera access is enabled
  4. Try again: python main.py


PROBLEM: "FileNotFoundError: logs directory"
─────────────────────────────────────────────────────────────────────────────
Fix: Directories not created
  1. In PowerShell, run:
     
     mkdir logs reports evidence archived_reports

  2. Try again: python main.py


PROBLEM: Report PDF not generating
─────────────────────────────────────────────────────────────────────────────
Fix: Check reportlab installation
  1. Run:
     
     pip install reportlab --force-reinstall

  2. Check reports/ folder has write permissions
  3. Try again
